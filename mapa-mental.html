Mapa Mental — Estudo

Monte seus próprios mapas. Tudo fica salvo automaticamente neste navegador.

TabAdiciona um filho ao nó selecionado e já entra no modo de edição
EnterAdiciona um irmão depois do nó selecionado
F2 / 2× cliqueEdita o texto do nó
Enter (editando)Confirma (não cria nó nenhum) · Shift+Enter insere quebra de linha no nó
Tab (editando)Confirma e cria um filho
EscCancela a edição / limpa a seleção
Del / BackspaceExclui o nó selecionado e seus descendentes
← ↑ → ↓Navega entre os nós (←/→ também recolhe/expande)
Alt+↑ / Alt+↓Reordena o nó entre os irmãos
Arrastar nóA guia mostra a marca no nó mais próximo do cursor: acima/abaixo dele reordena (mesmo nível), no meio dele vira filho. Esc cancela o arrasto
Roda / + / -Zoom · barra de espaço ajusta à tela
Ctrl+Z / Ctrl+YDesfazer / refazer
Cor do nóBotão de cor na barra de ações → escolha um tom. Shift pinta o ramo inteiro (nó + descendentes) · Alt pinta os irmãos (nós do mesmo pai) · Shift+Alt = irmãos + ramos
ReferênciasBotão 🔗 na barra de ações do nó (após "Cor do nó"): abre a caixa de referências — links (CF, slide, figura, docx…) para abrir, e adicionar/remover. Nós que já têm referência ganham um 🔗 no canto (visível ao passar o mouse / selecionar)
Fonte: PastaVincula uma pasta local (ex.: conteudo/mapa mental/); cada mapa vira um .json ali, além do navegador (Chrome/Edge). Edita e salva
Fonte: RepoLê os mapas de uma URL (ex.: GitHub Pages): baixa index.json + cada .json. Fica somente leitura — dá pra ver, navegar, recolher e baixar PNG, mas não editar nem salvar. Também abre por ?maps=<url>
